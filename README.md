# Speechify Desktop

A native Linux desktop text-to-speech application.

## Technology

- Python 3.12
- PySide6
- Kokoro (planned)
- Piper (planned)

## Features

- Desktop text reading
- Voice selection
- Adjustable reading speed
- Offline speech generation
- Synchronized text highlighting
- PDF reading

## Development

Activate the virtual environment:

```bash
source .venv/bin/activate
```

Run the application:

```bash
python src/main.py
```
